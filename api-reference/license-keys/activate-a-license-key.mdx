---
title: "Activate a License Key"
openapi: post /license-keys/activate
---

Activate a license key for a specific device or machine instance. This endpoint increments the active instances count and returns a unique `instance_id`.

This endpoint is **Client-Safe**. You do not need to provide your `blnk_live_` secret key. You can call this directly from a desktop application (like Electron, Tauri, or Swift) by simply providing the `license_key` and an optional `instance_name`.

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.blink.store/v1/license-keys/activate \
  --header 'Content-Type: application/json' \
  --data '{
    "license_key": "YOUR_LICENSE_KEY_STRING",
    "instance_name": "Omar'\''s MacBook Pro",
    "product_id": "OPTIONAL_PRODUCT_ID"
  }'
```

```javascript JavaScript
fetch("https://api.blink.store/v1/license-keys/activate", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    "license_key": "YOUR_LICENSE_KEY_STRING",
    "instance_name": "Omar's MacBook Pro",
    "product_id": "OPTIONAL_PRODUCT_ID"
  })
})
.then(response => response.json())
.then(data => console.log(data));
```

</RequestExample>
