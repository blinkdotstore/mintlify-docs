Import from:

- **Blink:** In case you have an existing Blink store and would like to migrate products to a new store, generate an API key under your Developer tab and paste it here to run the import.
- **URL:** nter any valid product URL. Blink will automatically scrape the public product details and import it into your dashboard as a draft.
- **Polar:** Enter your Polar API key to automatically import your products. [‭‬<u>Learn how to generate a Polar API key</u>](https://polar.sh/docs/api-reference/introduction)
- **Lemon Squeezy:** Enter your Lemon Squeezy API key to automatically import your products. ‭[Learn how to generate a Lemon Squeezy API key](https://docs.lemonsqueezy.com/guides/developer-guide/getting-started)
- **Gumroad:** Enter your Gumroad application API key to automatically import your products. ‬[Learn how to generate a Gumroad Access Token](https://gumroad.com/help/article/280-create-application-api)
- **Paddle:** Enter your Paddle API key to automatically import your products.[‭‬Learn how to generate a Paddle API key](https://developer.paddle.com/api-reference/about/authentication/)
- **Whop:** Enter your Whop API key to automatically import your products. [‭‬Learn how to generate a Whop API key](https://docs.whop.com/developer/api/quickstart)
- **Dodo Payments:** Enter your Dodo Payments API key to automatically import your products. [‭‬Learn how to generate a Dodo Payments API key](https://docs.dodopayments.com/developer-resources/integration-guide)<br />
